## Polecenie

Wyjaśnij własnymi słowami różnicę między granicą systemu, granicą kontekstu i zakresem wytwarzania. Czy informacja, że element pozostaje niezmieniony, wystarcza do pominięcia go w analizie wymagań? Podaj powód.

## Rubryka

osobno ocenić trzy rozróżnienia i powód. Granica systemu oddziela przedmiot analizy; granica kontekstu ogranicza istotne otoczenie; scope określa możliwość kształtowania. Brak zmiany nie wystarcza do pominięcia, jeżeli element wpływa na wymagania. Akceptować równoważny język. Odpowiedź „nie, bo wszystko należy analizować” nie spełnia warunku istotności; samo „nie” jest niepełne. „Niezmieniany element zawsze zewnętrzny” — błąd. S-A1/S-A2. Pomiar rozumienia KRY-A01 jest częściowy; nie L3. Ocena: wskazany oceniający według rubryki albo jawna samoocena; bez punktów CPRE.

**Błąd krytyczny:** Pominięcie znanego istotnego wpływu wyłącznie z powodu braku zmiany albo utożsamienie scope z granicą systemu.

**Odpowiedzi równoważne i graniczne:** Własny poprawny opis różnicy granic i wpływu jest równoważny; sama etykieta lub samo nie bez powodu jest częściowe.

**Podstawa źródłowa:** C-S02/C-S03 3.3.0 §2.2 zasada 4 s.16; C-S06 2.2.0 Context boundary s.12, System boundary s.13, Context s.17, Scope s.35; C-S07 1.3.2 §2.2.4 s.22–24

Ocena: jawna samoocena, bez punktów CPRE. Wymagane są wszystkie wskazane rozróżnienia; poprawne równoważne sformułowania są dopuszczalne.
