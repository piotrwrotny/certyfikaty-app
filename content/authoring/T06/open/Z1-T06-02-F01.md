## Polecenie

Podaj krótki sens każdego z sześciu terminów EU2. Nie wyjaśniaj jeszcze ważności dziewięciu zasad.

## Rubryka

| Element konieczny / model odpowiedzi | Ocena lokalna |
| --- | --- |
| Requirement: potrzeba, wymagana właściwość/zdolność lub jej zapis; RE: systematyczne specyfikowanie i zarządzanie z celem zrozumienia potrzeb i zmniejszenia ryzyka. | Spełnione: sens zachowany; częściowo: fragment bez pełnego rozróżnienia; niespełnione: brak lub sprzeczność. |
| Stakeholder: osoba/organizacja wpływająca na wymagania lub dotknięta systemem; context: istotne otoczenie. | Spełnione: sens zachowany; częściowo: fragment bez pełnego rozróżnienia; niespełnione: brak lub sprzeczność. |
| Shared understanding: wspólna podstawa znaczeń; validation: potwierdzenie dopasowania do potrzeb. | Spełnione: sens zachowany; częściowo: fragment bez pełnego rozróżnienia; niespełnione: brak lub sprzeczność. |

**Odpowiedzi równoważne i graniczne:** Wystarczy jeden poprawny sens requirement, jeśli nie neguje pozostałych; pełniejszy recall trzech sensów jest w T01.

**Błąd krytyczny:** Redukowanie stakeholder do user lub validation wyłącznie do poprawności zapisu.

Pełne wykonanie obejmuje wszystkie elementy i nie zawiera błędu krytycznego. Samoocena według rubryki nie daje punktów CPRE; wybór zamknięty nie zastępuje tego wykonania.
