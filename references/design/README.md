# IREB CPRE — pakiet projektowy D v0.1

Zacznij od `IREB_CPRE_D_Mockup_Atlas_v0.1.html`. Atlas i osobny `IREB_CPRE_D_Prototype_v0.1.html` są samowystarczalne. Folder `visuals` zawiera rzeczywiste makiety desktop i telefonu. Pięć plików D01–D05 stanowi specyfikację; osobna propozycja START nie została zastosowana do źródeł projektu.

Wybrany kierunek: Skupiona sesja. Właściciel wskazał tę organizację w rozmowie; przyjęcie całego D i G2/G3/G4 pozostaje otwarte. Przykłady i wyniki prototypu są demonstracyjne. Dostępne C03 v0.1 miało 0/3 gotowych pakietów. K-04 zachowano.

Nie ma backendu, integracji ani wdrożenia. Prototyp nie jest dopuszczonym kursem, testem CPRE lub chronioną rezerwą. Review projektu nie jest badaniem użytkowników ani dowodem skuteczności uczenia. Warunki późniejszego handoffu Claude Code są w D05.
