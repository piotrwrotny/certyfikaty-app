## C04-08 — Przeliczenie każdego opracowanego itemu

To **syntetyczne wektory obliczeń**, nie wyniki fikcyjnych ani rzeczywistych uczniów. ∅ lub „–” oznacza brak odpowiedzi; T=Prawda, F=Fałsz, B=obie wartości w jednym wierszu. Nadmiar A i podwójny K mogą pochodzić z nieprawidłowego zapisu; nie są postulatem dopuszczenia ich w zwykłej obsłudze produktu.

Źródło: C-S04 5.6.2 §2; reguły zaakceptowane w Blueprint F11 i B01-07. Dokładne ułamki pozostają w obliczeniu; zapis dziesiętny służy wyłącznie prezentacji.

### Cztery A — 20 przypadków

W A nie istnieje wynik częściowy. Pięć poniższych zapisów dla każdego itemu obejmuje poprawny, błędny, pusty i dwa nadmiarowe.

| Item | w / klucz | Poprawny | Błędny | Pusty | Nadmiar z kluczem | Wszystkie opcje |
|---|---|---:|---:|---:|---:|---:|
| C-A-B01 | 1 / d | d → 1 | a → 0 | ∅ → 0 | a,d → 0 | a,b,c,d → 0 |
| C-A-F01 | 1 / a | a → 1 | b → 0 | ∅ → 0 | a,b → 0 | a,b,c,d → 0 |
| C-A-D01 | 1 / c | c → 1 | a → 0 | ∅ → 0 | a,c → 0 | a,b,c,d → 0 |
| C-P-D01 | 1 / d | d → 1 | b → 0 | ∅ → 0 | b,d → 0 | a,b,c,d → 0 |

**Ważne:** C-P-D01 należy do pakietu rodzajów wymagań, ale ma format A. Nie otrzymuje punktacji P tylko z powodu prefiksu pakietu.

### C-P-B01 — 7 przypadków

w=2, k=2, klucz c,e; trafny wybór przy n≤2 daje 1 punkt.

| Odpowiedź | n / trafne c | Obliczenie | Punkty |
|---|---|---|---:|
| c,e | 2 / 2 | 2×2/2 | 2 |
| c | 1 / 1 | 2×1/2 | 1 |
| a,c | 2 / 1 | 2×1/2 | 1 |
| a,b | 2 / 0 | 2×0/2 | 0 |
| ∅ | 0 / 0 | 2×0/2 | 0 |
| a,c,e | 3 / 2 | n>k, całość zerowana | 0 |
| a,b,c,d,e | 5 / 2 | n>k, całość zerowana | 0 |

Nie ma dodatkowych punktów za niewybrane a/b/d. Pominięte e jest objaśniane, chociaż nie zostało kliknięte.

### C-P-F01 — 7 przypadków

w=3, k=2, klucz b,c; poprawny wybór przy n≤2 daje 3/2 punktu.

| Odpowiedź | n / trafne c | Obliczenie | Punkty |
|---|---|---|---:|
| b,c | 2 / 2 | 3×2/2 | 3 |
| b | 1 / 1 | 3×1/2 | 3/2 |
| a,b | 2 / 1 | 3×1/2 | 3/2 |
| a,d | 2 / 0 | 3×0/2 | 0 |
| ∅ | 0 / 0 | 3×0/2 | 0 |

## C04-11 — Najbliższy konkretny krok do G2

**Zlecić odrębne kompetentne review C01–C04 v0.2, przede wszystkim wszystkich 16 aktywności i 38 rozstrzygnięć C03.** Nie należy najpierw wracać do G1 ani rozpoczynać kolejnego ogólnego badania pedagogicznego.

Materiał dla recenzenta jest kompletny:

1. Najpierw rozwiązać dziewięć stemów [Q] oraz siedem otwartych poleceń bez konsultowania [R]; odnotować własną odpowiedź, niejasności i konieczne założenia.
2. Następnie porównać wszystkie klucze i rationale, źródłowe lokalizacje, EO/poziomy i rubryki. Osobno ocenić „każde zawężenie = constraint” w C-P-D01 i zakres każdego punktu K.
3. Sprawdzić scoring w C04-08 oraz warunki widoczności. Trafna ocena zamknięta nie poświadcza otwartego uzasadnienia.
4. Ocenić dziewięć par R21 i powiązania z ilustracjami B03/D12. Dla każdego delayed zdecydować: właściwy kandydat nowej rodziny / bliski wariant / wymaga przepisania. Nie zatwierdzać nowości przez samo nowe ID.
5. Sprawdzić język PL/EN, dostępność tekstu, prawa obecnego i planowanego użycia. Nie przenosić automatycznie zgody na review do publicznego produktu.
6. Każdą uwagę zapisać: identyfikator materiału i rewizja, źródło/warunek, waga, poprawka, wynik ponownego sprawdzenia. Wątpliwy klucz wstrzymać.
7. Zarejestrować rzeczywistego recenzenta, datę, kompetencje, zakres i decyzję: zmiany wymagane / dopuszczone do określonego użycia / wyłączenie. Sama zgodność dwóch odpowiedzi LLM nie zamyka C-AC-12.

To instrukcja następnego review, nie zapis jego wykonania. Jedna odrębna kompetentna osoba może łączyć zakresy zgodnie z B, bez fikcyjnego mnożenia recenzentów. Zakres zgody na review AI dla B w G1 nie jest automatyczną zgodą dla C.

Po rozliczeniu review właściciel może ocenić **G2 dla tego wycinka i określonego użycia**. Dopiero osobno G3: przebiegi A/P/K, przejście do wiedzy, korekta, FU, powrót i symulacja odroczonej próby na przyjętych wersjach. Walkthrough z moderatorem/kartami nie wymaga implementacji i nie poświadcza empirycznej retencji.
